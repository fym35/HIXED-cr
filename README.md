# HIXED
Code releases of Game Dev project https://hixed.eu
<br>
<br>
In three branches
  - crv-v1:
    Corresponds to build of the same name done recently,
    based on dev25 but refractored for legal compliance, MIT Licensed
  - dev25:
     Mostly original sources that should roughly coresspond to dev25 builds from around early 2024
     Unfortunately cannot be legally open-licensed, but are released for refference
  - legacy-2021
     Archived original code from somewhere around mid-2021, likely  older than 1.1
     Same situation as dev25, cannot be open-licensed
Sources between these branches can be considered lost media as there was no VCS on the project between 2022-2024
